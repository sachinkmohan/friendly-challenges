# Triage Labels

The skills speak in terms of canonical triage roles. This file maps those roles to the label strings in this repo's Linear team (Sachin).

## State roles

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

## Category roles

| Role          | Label in our tracker |
| ------------- | -------------------- |
| `bug`         | `Bug`                |
| `enhancement` | `Feature`            |

Linear also has an `Improvement` label. Treat it as `enhancement` when you read an issue, but apply `Feature` when you triage one.

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the matching label string from these tables.

Edit the "Label in our tracker" column to match whatever vocabulary you actually use.
